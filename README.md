# Server

## Запуск проекта
- Требования:
  - Node.js 18+
  - npm (или pnpm/yarn)
  - PostgreSQL 13+
- Установка:
  - Установить зависимости: `npm install`
  - Сборка (если используется TypeScript): `npm run build`
- Режимы запуска:
  - Разработка: `npm run dev` (автоперезапуск)
  - Продакшен: `npm start` (после сборки)
- Порт:
  - Используется `APP_PORT` из `.env` (по умолчанию 3300).

## Переменные окружения
Создайте файл `.env` (можно на основе `example.env`) со значениями:
- Загрузка `.env` выполняется на этапе старта приложения (через `dotenv`).
- Поведение синхронизации БД (если используется ORM):
    - development: `alter: true` (мягкие миграции)
    - production: `alter: false`

## Роутинг и middleware
- Точка входа: `src/index.ts` — инициализация Express-приложения и сервера.
- Конфигурация сервера: `src/Server.ts`
    - Подключаемые middleware:
        - `morgan('combined')` — HTTP-логи
        - `cors(...)` — CORS-политика в зависимости от `NODE_ENV`
        - `helmet()` — базовые заголовки безопасности
        - `express.json()` и `express.urlencoded({ extended: true })` — парсинг тела
    - Маршруты инициализируются через `src/routes` (класс/модуль `Routes`).
        - Новые эндпоинты добавляйте в соответствующие роутеры внутри `src/routes`.

## Быстрый старт
1) Скопируйте пример окружения: `cp example.env .env` и отредактируйте значения.
2) Запустите БД PostgreSQL и убедитесь, что доступна по `DB_HOST/DB_PORT` с указанными `DB_USER/DB_PASSWORD`.
3) Установите зависимости: `npm install`
4) Запустите в dev-режиме: `npm run dev`
5) Проверьте здоровье/маршрут: `http://localhost:3300` (или ваш `APP_PORT`)

## Отладка
- Конфликт порта: измените `APP_PORT` в `.env`.
- Подключение к БД: проверьте креды и сетевую доступность, убедитесь, что пользователь имеет права на `DB_NAME`.
- Логи: смотрите вывод `morgan` и сообщения синхронизации БД в консоли.

# Client

## Предварительные требования
- Node.js >= 18
- npm >= 9 (или pnpm/yarn)

## Установка
- npm install

## Разработка
- Запуск dev-сервера: npm run dev
- Откройте http://localhost:5173 (или адрес, указанный в консоли)

## Сборка
- Продакшн-сборка: npm run build
- Директория сборки: dist/

## Предпросмотр продакшн-сборки
- npm run preview

При необходимости обновите скрипты в package.json в соответствии с используемыми инструментами.

## Конфигурация окружения
- Создайте файл .env (и при необходимости .env.local)
- Примеры переменных (Vite):
    - VITE_SERVER_PATH=https://your-api.example.com
    - VITE_URL_DEV_API=http://localhost:3300/api
- Доступ к переменным в коде: import.meta.env.VITE_SERVER_PATH

Примечания:
- Не коммитьте секреты. Добавьте .env.local в .gitignore.
